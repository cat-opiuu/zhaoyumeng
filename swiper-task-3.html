💬 与 AI 的关键对话记录（提示词 + 重要往返）

提示词：

为光影展轮播增加 keyboard 键盘控制，要求轮播不在可视区域时不响应方向键，
避免滚动页面时误翻看不见的轮播。

AI 第一次回答的问题：只写了 keyboard: true，没有视口限制——页面一滚动，按方向键就会误翻看不见的轮播。

追问后修正（最终配置）：

keyboard: {
  enabled: true,          // 开启键盘控制
  onlyInViewport: true,   // 仅当轮播在视口内时才响应方向键
}
答辩四连问预答：
① 这段代码什么意思？keyboard 模块监听键盘方向键翻页；enabled 开启模块；onlyInViewport 限定轮播进入视口才接管按键。
② AI 第一次给的哪里不对？只写了 keyboard: true，没有视口限制，滚动页面后按方向键会误翻看不见的轮播。
③ 你改了什么？补上 onlyInViewport: true，并同步加到 destroy 后重建的配置里，否则切换效果后键盘控制会丢。
④ 新参数的作用 + 现场改 delay：把 autoplay.delay 从 3200 改成 2600，翻页间隔缩短、节奏变快；预期变化是每 2.6 秒自动翻一张，拖动后依旧继续自动播放。
