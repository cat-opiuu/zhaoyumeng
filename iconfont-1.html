Font Awesome 字体图标

字体图标把每一枚图标铸成字体文件里的一个字。浏览器像排版文字一样渲染它： 一个 class 名对应一个码点，颜色交给 color，大小交给 font-size—— 它天生与文字同呼吸。

载体
字体文件（woff2 / ttf），经 @font-face 声明
引入
<link> 加载一份 CSS，字体随用随取
渲染
文本字形，与文字同一行内排版
着色
单色，跟随 CSS color 属性
<i class="fa-solid fa-house"></i>　fa-house 的码点是 \f015　点击下方任意样张可复制此写法
